自托管的 Gravatar 兼容头像代理

内置本地 AI 内容合规审核，确定性兜底头像，零外部重依赖。 把头像 URL 中的 Gravatar 域名换成本服务，即完成零改动接入。

GitHub 仓库 接入方式

核心特性

为社区、博客与协作平台解决头像接入的合规、延迟与架构三大痛点。

🔄

Gravatar 原生兼容

完整支持 MD5 / SHA-256 哈希、尺寸裁剪、强制默认图与 .jpg/.png 后缀协商，下游零改动接入。

🛡️

本地 AI 内容审核

内置轻量 ONNX 模型执行 SFW / NSFW / NSFL 三分类检测，CPU 单张推理仅数十毫秒，原图未审绝不外发。

🎨

确定性兜底头像

待审核或被拦截时，基于哈希种子实时渲染 DiceBear 几何/插画面孔，同一哈希输出永远一致。

📦

零外部重依赖

元数据使用嵌入式 SQLite（WAL），图片存本地磁盘，无需 Redis 或消息中间件，单二进制即可运行。

🔒

生产级安全防护

SSRF 白名单与 IP 校验、解压缩炸弹防护、魔数嗅探与 EXIF 剥离重编码，深度防御。

⚡

CDN 友好

精确细分的 Cache-Control 策略，支持 Cloudflare Cache-Tag 与 Fastly Surrogate-Key 毫秒级主动失效。

三步接入

任何已使用 Gravatar 的应用，只需替换域名即可迁移到本服务。

1

计算邮箱哈希

对用户邮箱取 md5 或 sha256，与 Gravatar 规则完全一致。

2

替换请求域名

将 secure.gravatar.com 替换为 avater.juniortree.com。

3

完成

尺寸、默认图等查询参数原样保留，无需任何其他改动。

# 之前
GET https://secure.gravatar.com/avatar/<md5-or-sha256>?s=80&d=identicon

# 之后（本实例）
GET https://avater.juniortree.com/avatar/<md5-or-sha256>?s=80&d=identicon
